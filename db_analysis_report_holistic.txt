    CREATE VIEW DimEquipment AS
        SELECT DISTINCT
            EquipmentNumber,
            Material,
            "Serial#" as SerialNumber,
            Modality,
            "SAP Material description" as MaterialDescription,
            -- Get the most recent information for each equipment
            (SELECT CustomerName 
             FROM combined_data cd2 
             WHERE cd2.EquipmentNumber = cd.EquipmentNumber 
             ORDER BY cd2.DateKey_fk DESC 
             LIMIT 1) as LastKnownCustomer,
            (SELECT "Zone/Regions" 
             FROM combined_data cd2 
             WHERE cd2.EquipmentNumber = cd.EquipmentNumber 
             ORDER BY cd2.DateKey_fk DESC 
             LIMIT 1) as LastKnownRegion,
            (SELECT City 
             FROM combined_data cd2 
             WHERE cd2.EquipmentNumber = cd.EquipmentNumber 
             ORDER BY cd2.DateKey_fk DESC 
             LIMIT 1) as LastKnownCity,
            (SELECT Districts 
             FROM combined_data cd2 
             WHERE cd2.EquipmentNumber = cd.EquipmentNumber 
             ORDER BY cd2.DateKey_fk DESC 
             LIMIT 1) as LastKnownDistrict,
            (SELECT Market 
             FROM combined_data cd2 
             WHERE cd2.EquipmentNumber = cd.EquipmentNumber 
             ORDER BY cd2.DateKey_fk DESC 
             LIMIT 1) as LastKnownMarket,
            -- First and last seen dates
            MIN(DateKey_fk) as FirstSeenDate,
            MAX(DateKey_fk) as LastSeenDate,
            -- Count of records for this equipment
            COUNT(*) as TotalRecords
        FROM combined_data cd
        WHERE EquipmentNumber IS NOT NULL
        GROUP BY EquipmentNumber, Material, "Serial#", Modality, "SAP Material description"

REUSABLE STATE MAPPING PATTERN:
-------------------------------
This pattern can be applied to any project needing geographic normalization:

1. Create a mapping table with columns:
   - Source value (e.g., State, Region, LocationCode)
   - Intermediate normalization (optional)
   - Canonical target value

2. SQL to apply mapping:
   SELECT source.*, mapping.CanonicalRegion
   FROM source_table source
   LEFT JOIN mapping_table mapping ON source.RawRegion = mapping.SourceValue

3. ETL best practices:
   - Normalize case during import (UPPER/LOWER)
   - Trim whitespace
   - Log unmapped values for review
   - Run periodic audits for new values

4. Validation query template:
   SELECT DISTINCT RawValue, COUNT(*) 
   FROM source_table 
   WHERE RawValue NOT IN (SELECT SourceValue FROM mapping_table)
   GROUP BY RawValue;
